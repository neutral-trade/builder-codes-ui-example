# Contributing

This repository is intentionally minimal: it demonstrates the supported
Widget, REST, and SDK paths without becoming an application framework.

Bug fixes and corrections should stay focused and include the relevant tests.
Run `pnpm test`, `pnpm typecheck`, `pnpm lint`, and `pnpm build` before opening
a pull request.

Send feature requests and integration proposals to
[partnerships@neutral.trade](mailto:partnerships@neutral.trade).
